> 🎮 小方工作室 · 用心做好游戏 · [fanggame.company](https://fanggame.company)
> 📧 联系：xiaofangstudio@outlook.com

> 当前最新版本：**v1.7 Alpha · FlphaLit 引擎**（FlphaLit = 自研的轻量本地语言模型，算力 **2.4B 参数 · 3584 维 · 15 层纵深 · 28 头注意力**，权重**可训练**（AdamW + 反向传播 + LoRA），int8 量化常驻 ≤ 3GB）

## 🚀 怎么启动（最简单的用法）

### 方式一：双击一键启动（推荐）

双击桌面「AI 小方」文件夹里的 **`启动小方.bat`**，搞定。

这个脚本会自动帮你：
1. 检测 Python —— 没有就自动下载安装 Python 3.12
2. 检测依赖（numpy / colorama / pyfiglet / ddgs / psutil / requests / beautifulsoup4）—— 缺了就自动 pip 安装
3. 检测有没有 NVIDIA 显卡 —— 有就启用 GPU 加速（CuPy），没有自动用 CPU 硬算
4. 启动小方

### 方式二：命令行手动启动

```bash
# 进入项目目录后，运行主程序即可（settings 和数据文件会被自动加载）
python xiaofang_v17alpha.py
```

> 小提示：`xiaofang_settings.py` 是设置文件，一般不用手动运行；小方会在聊天里帮你改设置。

### 基础要求
- Windows 系统（bat 一键启动基于 Windows）
- Python 3.10+（推荐 3.12，脚本会自动装）
- 独立显卡可选——有就更快，没有也能跑

## 🧠 架构说明（技术内幕）

小方不依赖任何云端大模型，是一条**完整的本地小型语言模型流水线**：

```
你输入(逐键读取, 回车才提交) → Tokenizer(分词) → 意图/情绪识别
        → 深度思考第①层(Transformer 逐词生成) → Transformer 自验(相似度/置信度)
        → 深度思考第②层(再生成) → Transformer 再验 → 达标才交付
        → 回答选择与润色 → 输出到终止符 </s>（带打字机效果）
```

核心模块：

| 文件 | 职责 |
|------|------|
| `xiaofang_v17alpha.py` | 主程序。引擎入口、UI、对话循环、两层嵌套思考、可训练权重(优化器+反向传播)、数据库优先检索、进网页抠正文、多轮投稿 |
| `xiaofang_data_v17alpha.py` | 数据文件。常用词词典 / 情感词典 / emoji 库 / 回答词库 / 本地知识库 / 18 门语言语法表 / 代码示例 / 作文句库 / 工作室精准靶向条目 |
| `xiaofang_settings.py` | 设置持久化。在聊天里改设置会回写此文件（也可用它永久放开 3B/4B 尺度上限） |
| `xiaofang_memory_v17alpha.json` | 记忆数据。小方记住的"跟你聊过的事"（旧版记忆自动迁移，不丢已学内容） |
| `xiaofang_train_17.npz` | 训练成果。可训练主权重落盘，下次启动接着学（不想留可直接删，会自动重建） |
| `_smoke_test_v17alpha.py` | 全方位冒烟测试，覆盖引擎/训练/深想/联网/算术/创作等 150+ 用例（跑通输出 `SMOKE_OK`） |
| `启动小方.bat` | Windows 一键启动器（环境检测 + 依赖安装 + 启动） |

### 关键技术亮点

- **Tokenizer**：自研 FMM 正向最大匹配分词器，不依赖 jieba 等外部分词库
- **情感引擎**：内置情绪词典、emoji 权重、标点/表情情感判定（`！！`=激动、`😭`=难过）
- **多轮思考模式**：`think`（默认单轮）/ `multi`（多轮，类 DeepSeek 风格）/ `off`（直出最快）
- **硬件自适应**：启动时检测 CPU 核数 / 内存 / 显卡显存，自动匹配合适规模的向量空间，低配也能跑
- **GPU 加速**：有 NVIDIA 卡自动走 CuPy/CUDA，显存实时算；无卡自动回退 numpy CPU 硬算
- **联网搜索**：多后端（bing / baidu / ddgs / auto），可开关；**先查本地库，库里没有再上网**
- **数据库优先检索**：先算本地知识库命中分 + 实体对齐，够用就直接答（不浪费一次联网）；命中不足才联网，并记录联网理由（`db_hit` / `explicit` / `low_conf` / `db_enough`）
- **进网页读全文**：联网后**真的打开网页抠正文**（去 script/style/nav/footer，优先 article/main 语义容器），挑最相关的句子整合进回答，并标出来源与链接——不是只念搜索摘要
- **Transformer 升档**：v1.7 Alpha 维度破 **2B 参数 · 3584 维 · 15 层纵深 · 28 头注意力**（旗舰档 2.40B），int8 常驻压进 3GB，逐层 fp32 瞬时还原 → 8GB 显存 / 32GB 内存都安稳
- **权重可训练（v1.7 核心）**：初始权重**不再固定**——内置 **AdamW 优化器 + 反向传播**，只对最后 2 个 Block 做 **LoRA 低秩(rank=16)** 梯度更新，每轮 2 步、序列截断 48，纯 CPU 也不拖慢；训练成果落盘 `xiaofang_train_17.npz`，下次启动接着学
- **两层嵌套深度思考**：第①层由 Transformer 逐词生成 → 用同一套 Transformer 指标（相似度 cos + 归一化熵置信度）**自验** → 第②层再想 → **再验** → 达标才交付，思考内容每次都不一样，不是模板复读
- **输出到终止符**：生成一直走到 `</s>` 才停，配合 300s「静默上限」（不是总时长上限），长回答不会被硬生生截断
- **多行输入**：逐键读取（`msvcrt.getwch`）+ 回车后 15ms 前瞻窗口，超宽自动软换行，**按回车才提交**
- **多轮投稿**：认得「改成 / 改为 / 换成 / 加注释 / 换个算法 / 加长 / 换语言…」等自然改法，作文与代码都能第 N 稿接着第 N-1 稿继续改
- **精准靶向**：问「小方工作室出了几本小说」只答部数+书名+阅读网址；问纪念日就只答纪念日——绝不倒库、不夹带无关信息（自家情报只走本地，绝不联网瞎找）
- **3B / 4B 升级余量**：内存闸门 4.6GB，已预置 `Ultra4608 · 3.93B` / `Wide4096 · 3.12B` 档位，未来升档仍是**纯 CPU、无 GPU**，按需分片加载不溢出
- **靶向命中**：作文主题精确抽取实体（如「花」），不再反复写成"这个话题"
- **作文定向成篇**：认题目 + 认字数（阿拉伯/中文数字都认）+ 认「必须包含」要点，输出「📋 需求拆解」+ `## 正文`，按目标字数伸缩、跨段去重不写废话
- **代码真实现**：18 门语言语法速查表 + 37 条可跑示例，代码块带正确语言标注；没现成实现时**如实标注真实语言**，绝不张冠李戴
- **高难数学**：高斯消元解多元一次方程组 + 矩阵加/乘/行列式（安全 AST，杜绝 eval 注入）
- **询问机制**：代码没给语言、作文没给主题时反问，选项数量/内容由 AI 自定，**末项恒为「其他」**，支持单选/多选
- **Markdown 输出**：粗体、列表、标题、代码块结构化回复

## 🧩 关于 Vibe Coding

先说清楚：**这个项目不是从 v0.1 就开始 Vibe Coding 的**，请别误会 🤝

小方真正的演进分两个阶段：

| 阶段 | 版本区间 | 开发方式 |
|------|---------|---------|
| 🛠️ 前期手工开发 | `v0.1 → v0.4` | 以人工手写代码、逐行调试为主（初代分词、数据管理） |
| 🤖 后期 Vibe Coding | `v0.5 → v1.7`（**从 v0.5 起工作量剧增**） | 改用与 AI 对话、边聊边开发、逐步搓出来的方式 |

也就是说，**从 v0.5 开始**，功能复杂度快速上升（交互优化、性能提升、记忆增强、引擎重构），单靠手写已经撑不住迭代节奏，于是切换到 **Vibe Coding**：通过和 AI 对话、让 AI 批量产出与迭代，再从 0.5 一路推进到 v1.7 Alpha。

- 迭代中派生了不少**实验性变体**：`alpha`（先行）、`beta`（测试）、`pro`（增强）、`search`（检索）、`flash`（快速版）等
- 每一版都保留了独立源码，归档在 `历史版本/` 目录，方便随时回溯

所以小方既是你的聊天伙伴，也是「前期手工打磨、后期加速迭代」的真实开发样本——**Vibe Coding 是它中后期提速的手段，而不是它的起点**。

## 🔄 更新节奏 & 版本定位（重要）

### 📅 更新节奏

小方会**每周末更新**，而且每次更新的量都**不小**——功能、性能、记忆、体验会持续迭代。

### ⚙️ 性能承诺

- 小方**始终保证只需一颗中端 CPU（i7 / R7 这一档）就能流畅运行**，所以它的性能**必然有明确上限**，这是设计底线，不会靠堆配置突破。
- 但我们的思路是：**不做性能妥协**的偷懒版，而是**榨干你电脑的每一分算力**，用**最低的配置，跑出最牛逼的模型** 💪

### 🏷️ 版本号怎么读（别被编号骗了）

- 目前你看到的所有 `v1.x / v2.x / v3.x` 之类，**都只是「预览版」**，版本数字不代表正式程度。
- 真正的正式版**不按 `v几` 这种常规序列来**——当你在某天更新后，**突然看到冒出一个「FlphaLit 2」**，那才是**真正的正式版**。
- 所以：
  - 现在所有「正式版」（如 v1.6 正式版）其实只是 **预览版的正式版**；
  - 而凡是后缀带 **`Alpha`** 的，则还只是 **预览版的预览版**。

> 一句话记住：**别盯着 `v` 后面的数字，看到「FlphaLit 2」才是真正式版。**

## ❓ 常见问题

**没有 Python 怎么办？**
双击 `启动小方.bat`，它会自动下载安装 Python 3.12 并配好环境。

**电脑没独显能跑吗？**
能。会自动以 CPU 硬算模式运行，功能完全一样，只是思考稍慢一点点。

**小方要在周末才能更新，为什么？**
因为小方的作者是个**学生** 😴——**周末才能摸到电脑**。周一到周五都得上课写作业，只有放假了才能坐下来更新代码。

> 🌏 For foreign friends: The author is a **student**, so updates only happen on **weekends** — that's the only time he can touch his computer. And yes, that Chinese meme about "your computer gets smashed if you slack off in school" is **100% real** 😅 So if a week comes along where the update doesn't happen... it probably means the PC got destroyed. You've been warned.

**小方真的是纯自研吗？**
是的，**100% 是** ✅。前期只用 **NumPy** 手搓，后期想到显卡能加速，才加上了 **CuPy**——全程**没有使用任何 Transformer 库，也没有用 PyTorch** 之类的深度学习框架，一行一行都是自己写的。

**小方未来会有 Agent 框架吗？**
会有的。小方正在朝「能自己思考 + 能动手办事」的方向进化，Agent 能力在计划中——敬请期待 🚀（不过按上面的更新节奏……也得等周末。）

**未来可以吊打 GPT 吗？**
