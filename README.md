### 📌 关于"自研"这件事，先说清楚

小方的研发分两个阶段，**分界线是 Covi 2**：

| 阶段 | 版本区间 | 性质 | 说明 |
|------|---------|------|------|
| 🧪 **纯自研** | `v0.1 → Covi 1` | **100% 自研** | 整套 Transformer（注意力 / 归一化 / 前馈 / 反向传播）**全是纯 NumPy / CuPy 手写**，不用 PyTorch、不用任何现成 LLM 框架，连权重都是自己训练出来的 |
| 🤝 **半自研** | **`Covi 2` 起** | **自研 + 千问融合** | **自研的判断层**（前置 + 后置）+ **千问 3.5 的表达层**（生成主力）融合成一条链；千问只当"嘴"，**怎么想、该不该答、答完怎么验，仍然是小方自己说了算** |

> 所以准确的说法是：**Covi 1 及之前是纯自研，Covi 2 之后是半自研。** 这么做的原因是——自研引擎在"判断力"上很强（路由、情绪、违禁、检索、验算都是自己搓的），但在"长文本表达"上受限于单机算力；把千问接进来只补"表达"这一环，能让小方在**同样的低配电脑上**答得更好，而不必把整套引擎推倒重来。

## 🚀 Covi 2 到底改了什么（重大改革一览）

从 Covi 1 到 Covi 2，不是"加几个功能"，是**六处结构性改革**：

| # | 改革 | Covi 1 及之前 | Covi 2 |
|---|------|--------------|--------|
| 1 | **架构** | 纯自研单体：一套自研 Transformer 从头干到尾 | **三段式融合链**：自研判断层 → 千问表达层 → 自研复核层 |
| 2 | **交互重心** | 命令行 CLI（终端窗口、F1–F6 键位） | **Web 端成为主要交互方式**（独立窗口、流式、历史对话、滑块），CLI 保留 |
| 3 | **多模态** | 无（纯文本进出） | **图片 + 视频**：点按钮 / `Ctrl+V` 粘贴 / 拖拽，mmproj 视觉投影按需懒加载 |
| 4 | **产品线** | 三档 = 三个自研 `d_model`（Lite 2.07B / Pro 2.40B / Ultra 2.50B） | **四档 = 千问 3.5 四个 GGUF**（Satellite 0.8B / Asteroid 2B / Planet 4B / Corona 9B） |
| 5 | **插件生态** | 无（界面写死） | **从零长出一整套**：皮肤 + 技能（纯 Markdown 即插）+ 完整 Agent Skills（Remotion 官方 12 个 Skill） |
| 6 | **运行时** | 全自研推理（纯 NumPy / CuPy 手写） | 融入 **llama.cpp 运行时**（`llama-server` 子进程流式），自研层负责判断与复核 |

除了这六处，还有几条"看不见但很关键"的：

- **身份机制**——**不改模型**。千问的 GGUF 一个字节都没动，身份靠 `xiaofang_identity.py` 三层注入（GGUF 头审计 → 系统提示词 + 对话模板 → 输出端净化）。
- **学习机制换了老师**——自研网络照旧做反向传播，但监督目标变成**千问这一轮交付的句子**：拿千问当老师，越聊越贴自己的口径。
- **工程化补齐**——新增**版本注册表**（`xiaofang_versions.py`，两代引擎形状不同也能统一调度）、**显存管家**（`xiaofang_gpu.py`）、**子进程连坐保险**（`xiaofang_job.py`，不留后台）、**依赖指纹**（`DEP_SIG`，新依赖必定补装）。
- **模型分发方式**——千问那 11.8GB 不托管，直接指向**魔搭官方源**；用户跑一条脚本就下好，小方自己不当二道贩子。

## 🚀 怎么启动（最简单的用法）

### 方式一：双击一键启动（推荐）

双击「AI 小方」文件夹里的 **`启动小方.bat`**。**第一次**启动它会先把本机环境搭好（认型号 → 找 Python → 缺就自动装 → 补齐依赖），环境齐了才放**两层菜单**：**第一层选启动方式，第二层选模型档位**。

> ⚠️ **Covi 2 起，默认推荐走 Web**：多模态那条链（传图片 / 视频）只有网页的输入口走得通，模型档位也由网页那排下拉去切，所以 **Web 才是完整形态**；CLI 留给想盯命令行、或要跑历史版本的人。

```
  ════════════════════════════════════════════════════════════
   AI 小方  ·  Covi 2  启动台
  ════════════════════════════════════════════════════════════

   请选择启动方式，输入数字后回车：

   1  Web 界面      默认 · 本地开个端口，像应用一样单独弹一个窗口（不是浏览器标签页）
        └ 现代拟物 · 模型三级下拉 · 显存滑块 · 图片/视频多模态 · 历史对话
   2  命令行 CLI    原汁原味的终端窗口，键位最全，老版本也都走这条路

   直接回车 = 1 (Web)   ·   输入 q 退出
```

选完启动方式，才弹**档位菜单**（Covi 2 的四档直接对应千问 3.5 的四个 GGUF）：

```
   请选择要启动的版本，输入数字后回车：

   1  Satellite  0.8B   Q4_K_M   最快 · 轻量日常 · 秒回 · 千问 3.5 0.8B
        └ 已就位 · 703.3 MB
   2  Asteroid   2B     Q4_K_M   轻快 · 日常聊天与短问答 · 千问 3.5 2B
        └ 已就位 · 1.8 GB
   3  Planet     4B     Q4_K_M   主力 · 复杂问答与写代码 · 千问 3.5 4B
        └ 已就位 · 3.2 GB
   4  Corona     9B     Q4_K_S   最强 · 长题深想 · 多模态全开 · 千问 3.5 9B
        └ 已就位 · 5.9 GB
   4  历史       回看老版本（N 个系列）· 含分支 · 进三层页面挑
        └ 先选版本系列，再选真正的版本号 / 分支

> 档位行里的 **Q4_K_M / Q4_K_S** 是量化规格；下面 `└ 已就位 · x.x GB` 是这一档**本体 + 多模态投影**的合计体积。**没下完的档会照实标**——「本体还没下完 · 这一档先别选」或「只有本体 · 看不了图/视频(缺 mmproj)」，不假装有。

### 🧠 四档怎么选

四档的名字、参数量、上下文与多模态能力，一张表看全：

| 档位 | 融入的模型 | 参数量 | 上下文 | 量化 | 多模态 | 体积（本体+投影） | 定位 |
|------|-----------|--------|--------|------|--------|------------------|------|
| **Satellite** | `Qwen3.5-0.8B` | **0.8B** | 8192 | Q4_K_M | ✅ 图片 | ≈703 MB | 最快 · 轻量日常 · 秒回 |
| **Asteroid** | `Qwen3.5-2B` | **2B** | 8192 | Q4_K_M | ✅ 图片 | ≈1.8 GB | 轻快 · 日常聊天与短问答 |
| **Planet** | `Qwen3.5-4B` | **4B** | 12288 | Q4_K_M | ✅ 图片 | ≈3.2 GB | 主力 · 复杂问答与写代码 |
| **Corona** | `Qwen3.5-9B` | **9B** | 16384 | Q4_K_S | ✅ 图片 + 视频 | ≈5.9 GB | 最强 · 长题深想 · 多模态全开 |

**四档能力差别，说人话就是：**

- **Satellite（0.8B）**——秒回档。寒暄、查词、随手问问，几乎不占显存（≈1.5GB），老旧机器也能跑。
- **Asteroid（2B）**——日常档。短问答、日常聊天、简单代码片段，比 Satellite 明显更"接得住话"。
- **Planet（4B）**——主力档。**复杂问答 + 真写代码**是它的主战场，长上下文到 12288，一份完整源码贴进去也读得下。
- **Corona（9B）**——最强档。长题深想、多步推理、**视频也看得**（多模态全开），上下文 16384，代价是要 8GB+ 显存。

> **多模态是怎么回事**：四档都支持看图，靠的是每档配套的一个 `mmproj-F16.gguf` **视觉投影**（195MB ~ 876MB）。这个投影**按需懒加载**——你不发图，它就不装进显存；一发图，这一轮才临时挂上。所以"能看图"不等于"一直占着显存"。**视频**在 Corona 档走得最完整，其余档以图片为主。

> 四档**共用同一套小方**（自研判断层完全一样），区别只在"借哪副千问的嘴"。机器弱选 Satellite 秒回，机器好选 Corona 长题深想；**同一台机器上也能随时切**（Web 端点模型下拉即可，不用重启）。

### 📦 模型从哪来（重要）

Covi 2 的档位权重就是**千问 3.5 的 GGUF 文件本身**，需要先下到本机：

```bash
# 在 Covi2_模型/ 目录下执行（走魔搭 ModelScope 官方源，断点续传、已下全的自动跳过）
powershell -ExecutionPolicy Bypass -File .\Covi2_模型\_下载模型.ps1

# 在 Covi2_运行时/ 目录下执行（拉 llama.cpp 官方预编译运行时）
powershell -ExecutionPolicy Bypass -File .\Covi2_运行时\_拉取运行时.ps1
```

- **模型源**：魔搭 **`unsloth/Qwen3.5-*-GGUF`** 官方仓库（0.8B / 2B / 4B / 9B 各一个本体 + 一个 `mmproj-F16.gguf` 多模态投影，共 8 个文件）
- **运行时**：llama.cpp `b11160` CUDA 12.4 Windows x64 预编译包（自带 `llama-server.exe`）
- **为什么不让小方托管模型**：这 4 档模型合计 **11.8 GB**，**小方一个字节都没改过**（身份是靠系统提示词注入 + 输出端净化做的），所以直接指向官方源最省事、也最快——不需要小方自己当二道贩子
- **下载脚本自带**：`curl -C -` 断点续传 + `--retry 8` 重试；运行时那边还配了 12 路分片并发，绕开 GitHub 限速

## 🖥️ Web 界面（Covi 2 的主要交互方式）

**Covi 2 起，Web 是默认入口**——启动台第一层直接回车即进。它不是"给 CLI 套个壳"，而是**小方的完整形态**：多模态、模型热切换、历史对话管理这些能力，只在 Web 上走得通。

### 它是什么

本地起一个 Flask 服务（默认端口 **8799**），用 Edge / Chrome 以 `--app=` 的方式**单独弹一个独立窗口**（不是浏览器标签页），**关掉这个窗口，小方会跟着退掉**（网页每 1.5 秒发一次心跳，超过 10 秒收不到就顺手收起引擎，不留后台进程）。

引擎本身**一行业务逻辑都没改**，只是被 `xiaofang_web.py` 当"搬运工"端了起来：网页输入 → 写进 stdin → 引擎照常 print → 从 stdout 抄回网页（**SSE 流式**）。所以一套引擎能走遍所有档位与历史版本。

### Web 端有哪些特性

| 特性 | 说明 |
|------|------|
| 🎚️ **思考强度滑块** | 现场调"想多深"：**简单 1 轮 / 深度 3 轮 / 极致 5 轮**，快捷键 `Ctrl+1 / 2 / 3`；**热更新，不用重启** |
| 🔽 **模型三级下拉** | 网页里直接切 Satellite / Asteroid / Planet / Corona——切换即换脑子 |
| 🖼️ **多模态上传** | 点附件按钮 / `Ctrl+V` 粘贴 / **拖拽**都行，**带缩略图预览**；图片真喂给千问看，视频（`.mp4 / .mov / .mkv / .webm`，单件 ≤64MB）挂上画播放图标 |
| 💬 **历史对话管理** | 对话列表可**新建 / 删除 / 改名**，聊天记录存在 `Web对话/` |
| ⌨️ **流式打字机 + 消息排队** | 逐字打字机输出；连着发消息会**串行排队**，不打架、不乱序 |
| 🎨 **磨砂玻璃皮肤 + 背景图** | 半透明 / 模糊 / 饱和的拟物质感；背景图可自己换（放 `背景图/`） |
| 🧩 **插件栏（技能 + 皮肤）** | 纯 Markdown 丢进 `插件/` 就生效：`插件/skill/*.md` → 输入框底下那条横向滚动栏；`插件/personalization/*.md` → 「设置 · 个性化」里的皮肤卡 |
| 🔍 **快捷搜索** | `Ctrl+K` |
| 📊 **显存滑块** | 按本机显存现场调预算 |
| 🎬 **思考可视化** | 深度思考的过程在网页里看得见，不再是黑箱 |
| 🔢 **数字彩蛋** | 输入 `01020304` 有惊喜 🎁 |

> 🔒 **插件的能力边界是划死的**：插件能改界面（加技能、换皮肤），但**碰不到"发送 → 生成"那条管子**——插件改不了模型。这是设计上的一道锁。

**首次启动**会一次性把环境办好，按顺序走完下面这几步，全绿了才放出菜单：

1. **认型号** —— 读出本机 CPU 架构（x64 / ARM64 / x86）和 Windows 版本，决定该下哪个安装包
2. **找 Python** —— 依次试 `py` 启动器 → PATH 上的 `python`（自动跳过微软商店那个只会弹商店的占位程序）→ 直接翻 `%LOCALAPPDATA%\Programs\Python` 等安装目录（刚装好的 Python 刷新不到当前 PATH，只能翻盘找）
3. **没有就自己装** —— 交给 `xiaofang_bootstrap.ps1` 从 python.org 下载对应架构的安装包，**静默、只装当前用户、不弹 UAC、不建快捷方式**，装完再把解释器路径扫出来（优先 3.12.x）
4. **补齐依赖** —— numpy / colorama / pyfiglet / ddgs / psutil / requests / beautifulsoup4 / **flask**（Web 界面要用的），缺哪个装哪个；检测只看"装没装"，能用的模块一律按需懒加载
5. **选启动方式 → 选档位** —— 把选中的档位通过 `XF_TIER` 透传给主程序
6. **模型体检** —— 顺带看这一档的 GGUF 本体和 mmproj 投影齐没齐；没齐会**提示**你去跑下载脚本，**不会**替你偷偷拉 11.8 GB

走完这几步会在项目里留一个环境记号 `.xf_env_ok`（第一行记着解释器路径，另有**一行依赖指纹**）。**以后每次双击，只要记号还在、且里面记的解释器路径确实存在，上面几步全部跳过，直奔菜单** —— 没有第二次等待。若依赖清单以后加了新库（比如当初补 `flask`），指纹对不上，启动台会自动补装再放行——不会再因为时序漏装而报"缺模块"。

> 想跳过菜单直接指定：`启动小方.bat web`（直走 Web 界面）、`启动小方.bat cli`（走命令行、再选档位）、`启动小方.bat corona`（按名字直开 Corona 档）、`启动小方.bat --check` 只体检不启动。
> 想强制重来一遍自检：`启动小方.bat --reinstall-env`（先删掉记号，下次双击重新走一遍）。

### 方式二：命令行手动启动

```bash

### 基础要求（最低 & 建议配置）

| 项 | 最低配置（确定能跑） | 建议配置（用得更爽） |
|------|------|------|
| 操作系统 | Windows 10/11（bat 一键启动基于 Windows） | Windows 11 x64 |
| Python | 3.10+（推荐 3.12；没装的话首次启动会自动下载静默安装） | 3.12.x（启动台优先挑它） |
| 内存（RAM） | **16GB**（Satellite 档） | 32GB+（Corona 档更稳） |
| 显卡 | 无独显也能跑（CPU 推理，慢一些） | **NVIDIA 卡，8GB+ 显存**（llama.cpp CUDA 后端，快得多） |
| 显存（VRAM） | 0（不需要） | **8GB+**：Satellite ≈1.5GB / Asteroid ≈2.5GB / Planet ≈4GB / Corona ≈7GB（含视觉投影） |
| CPU | 随便一颗能跑 Windows 的 | i5/R5 及以上多核 |
| 磁盘 | 约 **3GB**（Satellite 一档模型 + 运行时） | 预留 **20GB+**（四档模型 11.8GB + 运行时 1.1GB + 历史版本归档） |
| 网络 | 首次需联网下模型；之后可离线跑 | 可联网（实时天气 / 全局搜索 / 代码加权） |
| 浏览器 | 无（走 CLI） | **Edge / Chrome**（Web 界面以 `--app=` 独立窗口打开） |

> **磁盘这笔账要算清**：Covi 2 的"档位"就是千问的 GGUF 文件，**下一档占一档的空间**——只下 Satellite 约 700MB，四档全下 11.8GB。运行时（llama.cpp）另算 1.1GB。**不用一次下全**，按需下一两档就够。
>
> **显存那列是实打实的**：千问的 GGUF 会整份进显存（llama.cpp 的 offload），所以 Corona 9B 建议 8GB 以上显存；显存不够会自动往 CPU 层回落，慢但能跑。Web 端还有**显存滑块**可以现场压预算。

## 🧩 插件生态 & Skill 生态（Covi 2 新增）

这是 Covi 2 里**最"长在用户手上"**的一块：小方的界面不再是被写死的，**你自己往文件夹里丢 Markdown，它就变**。不用改代码、不用重启、不用点编译。

### 两条线：皮肤（改长相）和技能（换干法）

| 文件夹 | 是什么 | 出现在哪 | 效果 |
|--------|--------|----------|------|
| `插件/personalization/` | **皮肤** | 网页「设置 · 个性化」里的卡片 | 换底色、改圆角、挪侧栏位置、加时钟/按钮、换背景…… |
| `插件/skill/` | **技能** | 网页输入框底下那条**横向滚动技能栏** | 点一下 = 把一段"预设指令"替你填进输入框，等于换个干法 |

> **一句话区分**：皮肤是**给同一辆车上漆**，技能是**换零件**——上漆不影响车怎么跑，换零件会。

### 它为什么叫「插件」不叫「美化」

因为**它会真的跑起来**。插件里写的是真代码，网页会当场执行它，所以能干的事比"换个颜色"多得多：

| 插件能干的事 | 举例 |
|---|---|
| 换样子 | 改底色、改圆角、换背景 |
| 挪位置 | 把侧栏挪到右下角、把产物面板摞到消息上面 |
| 加东西 | 加一个时钟、加一排快捷按钮、加一条自己的工具条 |
| 改内容 | 换掉某块里的文字和图标、给元素加减属性、加/去掉 class |
| 够到底层 | 伸手拿到页面里真正的元素，自己读它的内容、盯着它的变化 |
| 写网页写脚本 | 直接塞一整块 HTML，再塞一整段 JS 让它动起来 |
| 变轻快 | 把最耗显卡的效果关掉，滚动和切换就更跟手 |

### 怎么写：一个 `.md` 就够，三种代码块

插件的全部家当就是**一段 front matter + 三种代码块**，用记事本就能写：

````markdown
---
name: 我的第一个插件
desc: 把整个页面变成淡黄色
swatch: #fff8e1,#ffd54f
---

```xf-style
:root { --bg: #fff8e1; --bg-hi: #fffdf5; }
```

```xf-html
<div id="我的小工具条"><button>A</button><button>B</button></div>
```

```xf-script
XF.bg.color('linear-gradient(#fff8e1, #ffe082)');
XF.add('<div id="贴纸">柠檬</div>');
```
````

| 代码块 | 干什么 | 落到哪 |
|--------|--------|--------|
| `xf-style`（别名 `xf-css`） | 写 CSS | 整段塞进 `#xf-theme-layer`，**排在原样式表后面，同选择器你写的赢** |
| `xf-html` | 加一整块真 HTML | 落到 front matter 里 `host` 指定的选择器（不写就挂 `body` 末尾） |
| `xf-script` | 写真 JavaScript | 由 `XF` 这套接口干活（`XF.bg.color()` / `XF.add()` / `XF.find()` …） |

两条死规矩：**后缀必须是 `.md`**、**开头必须有 `---` 包住的 front matter**（`name` / `desc` / `swatch` / `host`，少写写错都不报错，只是那项空着）。只认 `skill/` 和 `personalization/` 这两个文件夹里**直接躺着的** `.md`，塞进子文件夹读不到。

### 生效机制：丢进去就显示，但不会自己动

1. **丢进去就显示**——把 `.md` 拖进 `插件/skill/` 或 `插件/personalization/`，回到网页把「设置 · 个性化」打开一次（本来就开着就点「重扫插件」），它就在列表里了。
2. **但不会自己应用**——新插件只是"待在那儿"，**必须你自己点它**（皮肤点「应用」，技能点一下名字）才开始干活。所以丢十个进去也不会把界面搞乱。
3. **记得住的只有你亲手指过的那一个**——关掉小方再打开，恢复的是你上次点过的那套；没点过的永远不生效。

> 🔒 **一根谁都跨不过去的线：插件改得了界面，改不了模型。** 发送消息 → 生成回答那条管子，插件碰不到。想让它"想得更快"，得改引擎，不是写插件。这是设计上的一道锁。

## 🧠 架构说明（技术内幕）

Covi 2 是一条**三段式融合链**——**自研的判断层**夹着**千问的表达层**：

```
你输入
  │
  ├─ ① Covi 前置层（自研）
  │     多语言识别 / 翻译 · 乱码拦截 · 违禁检测 · 情绪分析
  │     意图定向 · 本地知识库检索 · 确定性路由（算术 / 天气 / 时间 / 文件 / 出图）
  │     └ 命中就当场交付 —— 毫秒级，根本不惊动千问，省算力
  │
  ├─ ② 千问生成层（融入）
  │     小方身份系统提示词 + 检索到的本地资料 + 图片 / 视频
  │     └ llama-server 流式生成
  │
  └─ ③ Covi 后置层（自研）
        验算复核 · 违禁检测 · 身份净化 · emoji 落位 · 共情前缀 · 收尾
        └ 交付

暗线：千问每交付一句，小方自己的网络就拿这一轮当训练对做一次反向传播
      —— 拿千问当老师继续长。这才是"融合"，而不是"换芯"。
```

**接法很克制**：起一个 `llama-server.exe` 子进程（随机端口，绑 `127.0.0.1`）加载 GGUF，只用标准库 `urllib` 发 HTTP——**不引入任何推理框架、不 import torch**。进程隔离意味着**千问崩了不影响小方**，会自动降级；`xiaofang_job.py` 用 Windows Job Object（`KILL_ON_JOB_CLOSE`）给它收尸，**保证不留后台残留**。

### 身份是怎么做的（不改模型）

小方**没有改千问一个字节**，身份靠三层机制：

1. **系统提示词注入** —— `xiaofang_identity.py` 往对话里塞"你是 AI 小方"
2. **对话模板** —— 沿用千问的格式标记，但套的是小方自己的模板
3. **输出端净化** —— 万一它还是漏出"我是通义千问"，**当场改写**

> 这也是为什么**千问的 GGUF 可以直接从魔搭官方下载**——模型是原装的，所有"小方化"都发生在小方自己的代码里。

### 那自研的那套还在吗？

**在，而且还在长。** Covi 1 的整套自研引擎没有报废——它变成了 Covi 2 的**前后置判断层**，并且保留着**在线学习**能力（`xiaofang_train_covi2_档位.npz`）：千问每交付一句，自研网络就拿这轮做一次梯度更新，**拿千问当老师**。所以 Covi 2 不是"换芯"，是"长出了第二套本事"。

### 关键技术亮点

- **Tokenizer**：自研 FMM 正向最大匹配分词器，不依赖 jieba 等外部分词库
- **情感引擎**：内置情绪词典、emoji 权重、标点/表情情感判定（`！！`=激动、`😭`=难过）
- **多轮思考模式**：`think`（默认单轮）/ `multi`（多轮，类 DeepSeek 风格）/ `off`（直出最快）
- **硬件自适应**：启动时检测 CPU 核数 / 内存 / 显卡显存，自动匹配合适规模的向量空间，低配也能跑
- **GPU 加速**：有 NVIDIA 卡自动走 CuPy/CUDA，显存实时算；无卡自动回退 numpy CPU 硬算
- **联网搜索**：多后端（bing / baidu / ddgs / auto），可开关；**先查本地库，库里没有再上网**
- **数据库优先检索**：先算本地知识库命中分 + 实体对齐，够用就直接答（不浪费一次联网）；命中不足才联网，并记录联网理由（`db_hit` / `explicit` / `low_conf` / `db_enough`）
- **进网页读全文**：联网后**真的打开网页抠正文**（去 script/style/nav/footer，优先 article/main 语义容器），挑最相关的句子整合进回答，并标出来源与链接——不是只念搜索摘要
- **Transformer 升档 + 三档真正拉开**：v1.8 起四档雏形 → Covi1 起**参数真正阶梯化**——**Lite ≈ 2.07B（3328 维 · 26 头）/ Pro ≈ 2.40B（3584 维 · 28 头）/ Ultra ≈ 2.50B（3660 维 · 30 头）· 均 15 层**，int8 常驻压进 3GB，逐层 fp32 瞬时还原 → 8GB 显存 / 32GB 内存都安稳
- **权重可训练（v1.7 核心 + Covi1 预训练正式化）**：初始权重**不再固定、也不再是随机**——`Covi1` 的初始参数由自研训练脚本用文本语料**预训练出来**（`历史版本/_训练脚本存档/` 里的 `学习小说 / 学习语料 / 爬取语料` 训练完即归档），一启动就带语料学来的底子；发布后仍可**继续边聊边学**——内置 **AdamW 优化器 + 反向传播**，只对最后 2 个 Block 做 **LoRA 低秩(rank=16)** 梯度更新，每轮 2 步，纯 CPU 也不拖慢；训练成果落盘 `xiaofang_train_covi1_档位.npz`（按 Lite / Pro / Ultra 各存一份），下次启动接着学
- **在线问答对齐重构（v3.1 / v3.2）**：把"在线学习"从老版的「顺着问题往下续写」改成真正的「**给定问题 → 该答什么**」——
  - **① 只算答案的 loss（v3.1）**：问题侧 token 全填哨兵忽略项，不进 loss、不回传梯度、不参与归一化——模型学的是"怎么写答案"，不是"顺着往下接话"，从根上治"牛头不对马嘴"。
  - **② 长问题不再被砍**：训练序列截断从 48 抬到 192（问题侧先保底留 3/4），长指令、长答案都不再被裁掉半句。
  - **③ 学习闸门（v3.1）**：只有"检索命中分过线"或"知识库命中余弦过阈值"（完全命中时阈值折半）才允许学，凭空编的回答一律不进权重——**宁学得少，每条都要站得住**。
  - **④ 对齐"标准答案"而非自产句（v3.2）**：监督目标直接取**库内正文 / 联网正文**（标题+答案+补充），不再拿模型自己刚编的那句喂自己；命中后还检查"问题里的实义词在库正文里找不找得到"，答不上的记一笔**知识缺口**（给补库指路），并新增 `_ask_knowledge` 判据拦截"托我干活 / 问时效 / 主观索取"，避免把不相干的库正文当正确答案背下来。
  - 配套：`SEED_TOKENS` 按档位提到 160/256/384 词元让长问题整段吃进、`_learn_gap` 知识缺口留痕（去虚词噪声）、显存守门员兜底训练瞬时内存。
- **两层嵌套深度思考**：第①层由 Transformer 逐词生成 → 用同一套 Transformer 指标（相似度 cos + 归一化熵置信度）**自验** → 第②层再想 → **再验** → 达标才交付，思考内容每次都不一样，不是模板复读
- **输出到终止符**：生成一直走到 `</s>` 才停，配合 300s「静默上限」（不是总时长上限），长回答不会被硬生生截断
- **多行输入**：逐键读取（`msvcrt.getwch`）+ 回车后 15ms 前瞻窗口，超宽自动软换行，**按回车才提交**
- **多轮投稿**：认得「改成 / 改为 / 换成 / 加注释 / 换个算法 / 加长 / 换语言…」等自然改法，作文与代码都能第 N 稿接着第 N-1 稿继续改
- **精准靶向**：问「小方工作室出了几本小说」只答部数+书名+阅读网址；问纪念日就只答纪念日——绝不倒库、不夹带无关信息（自家情报只走本地，绝不联网瞎找）
- **建议询问 chips（v1.7 Flash）**：交付完成后由 `build_suggestions()` 按「本轮话题 + 回答形态 + 情绪」**确定性**推导 0~3 条黄色追问——数量由小方按话题自己定、同输入同输出（**不是随机**），推不出来就不给；chips 逐条记下屏幕行列坐标，**鼠标可直接点、也能用 ↑↓ 轮选**，选中即替你填进输入框，回车就发
- **输入 / 输出双闸门（v1.7 Flash）**：输入侧按 5 类规则拦下**危险物制作 / 色情获取 / 恐怖主义 / 反政 / 违法犯罪**，命中的话题直接拒绝、不进模型。**违禁限度已按实战放宽**：不再"单词级一命中就拦"，敏感词邻域（±12 字）若属于正常技术 / 科普 / 生活语境就判为误伤放行——`怎么杀死一个进程`、`游戏里怎么改枪的手感`、`病毒是怎么入侵电脑的`、`这么做违法吗` 都不会再被误拦，而 `怎么做炸弹` 这类**明确违禁意图照旧拒绝**。放宽也有底线：整句只要命中 `_BAN_HARD` 里的**核心违禁短语**（`做炸弹` / `炸弹配方` / `制作炸药` / `诈骗教程` / `洗钱教程` / `怎么盗号` / `伪造证件` …），本句内**不再享受任何正常语境豁免**，避免"夹个技术词就蒙混过关"。输出侧小方自己要说的话再过一遍同套规则；只命中"疑似敏感"观察词时，把 **「用户问题 + 小方要说的话」再送一回 Transformer 读一遍**（`_tf_review()`：自回归概率衡量这段话接得顺不顺），读得顺就放行、明显不顺才拦，判不出来时一律放行（宁可漏、不误伤）。**医学 / 生理语境自动豁免"色情"与"危险物"判定**（问「私处不舒服」给合理科普，而不是拒绝），而且只要判为医疗诉求，回完必附「我只是 AI，不是医生，查到的也不一定对，请及时就医」
- **输出前双重自我确认（v1.7 Flash）**：`_self_confirm()` 先问第①遍"**用户真的想要吗**"——人家给了具体任务、却回一堆"你可以跟我说…"的能力推销腔，直接剥掉；再问第②遍"**给的都是他想要的吗**"——只问一个邮箱却倒出整页工作室资料，只留命中那一段
- **文字画面路由（v1.7 Flash）**：`画一只小猫`、`写一个鹈鹕骑自行车` 这类"画 / 写一个具体东西"由**动词 + 量词正则**识别，直接给 ASCII 画面 + 4 格分镜，**绝不再回一段算法**；沾编程域的请求（`写一个防抖函数`）仍老实写代码，绝不抢活
- **联网结果回灌 Transformer（v1.7 Flash）**：抓到网页正文后**不直接甩给用户**，先**逐句过一遍 Transformer** 取自回归概率打分重排（`_tf_integrate`），由模型口径决定先说哪句、怎么整合，再落笔成回答
- **梗 / emoji 判读（v1.7 Flash）**：`_meme_scan` 认 36 条网络梗并计正负极性，情绪分随之加减（`yyds` 加分、`破防` 减分）；emoji 除极性外还读得出中文含义（`🗿`→"无语凝噎"）；问「XX 是什么梗」会正经解释；**带任务词时梗路由绝不抢答**
- **主体 × 焦点双层意图（v1.7 Flash 核心）**：旧路由只按"话题词"分流，从不判"用户问的是这个东西的哪一面"，于是问「有什么**好玩的**游戏」（要推荐）被答成「游戏是什么」（定义）、问「小方**你自己的架构**」（本体）被答成「小方工作室」、问「你**是不是 LLM**」（身份/原理）被答成「别家 AI 怎么搞」。新增 `_subject_of()`（取**最长**命中——「小方工作室」必须压过「小方」）+ `_focus_of()`（**降序**首命中——`recommend` 必须压过 `define`），两层组合决定应答形态；配 `_SELF_STRONG_KWS` 闸门与 `_MAKE_VERBS` 拦截，保证纯身份问候「你是什么框架」不被架构长文劫走
- **V1.7 Flash 提速档**：`FLASH_LEVEL` 0~3 四档 profile，只压**逐字显示延迟**、**嵌套采样 token 预算**和**短寒暄跳二层**，**不动模型、不动知识库、不动权重**——所以是"更快"，不是"更笨"
- **文体适配（v1.7 Flash）**：`STYLE_ALIAS`（长词优先）→ `STYLE_KB.kws` 两级识别出八种文体（搞笑/轻松/情感/宏大/悲情/悬疑/热血/温柔），`_style_ctx()` 把 `{t}/{c}` 填进**起句/主体/意象/收束**四组句，`_gen_essay` 成文时**真用这些句子覆盖通用句库**，需求拆解里明写「文体与调性」，同义写法自动归并（「沙雕」= 搞笑），没点名就老老实实用中性腔
- **代码素养（v1.7 Flash）**：`CODE_QUALITY_KB` 覆盖「什么是最好的代码 / 命名规范 / 代码优化 / 坏味道 / 上手路径」，命中关键词必须 **≥3 字**且需 `_HOWTO_HINT` 佐证，**绝不去抢"帮我写一个排序函数"这类真写码请求**
- **做游戏方法论（v1.7 Flash）**：`GAME_BUILD_KB` 给出**十步套路 + 变量命名对照表 + 手感调优清单**；`_creative_kind` 遇 `_GAME_METHOD_KWS` 主动让路，所以「怎么做游戏」拿到的是方法论而不是一份《一分钟方块》设计稿
- **长线任务（v1.7 Flash）**：`LONG_TASK_KB` 把一句大目标拆成阶段清单，`_long_save/_long_load` 状态落盘 `xiaofang_longtask.json`，支持「看进度 / 完成第 N 步」，**关掉重开也能接着走**
- **口语虚词归一（v1.7 Flash）**：「什么**才是**最好的代码」和「什么是最好的代码」是同一句话——`_oral_variants()` 统一抹平 `才是/才算/到底是/才叫/比较好` 这类虚词，**不许因为多一个字就漏识别**（漏识别 = 掉进通用模板 = 答非所问）
- **本地文件阅读（v1.8 Alpha）**：`_file_read_route()` 挂在回复链最前面（排在翻库/联网/长线任务之前）——**带路径的句子一旦被当普通提问就会答成别的**，所以先抢判。路径抽取 `_file_extract_path()` 认**引号定界 / Win 绝对路径 / Unix 绝对路径 / `./ ../ ~/` 相对路径 / 光杆文件名**五路，且**只把命中已知扩展名的词当文件**（不把普通词误当文件）；读法由 `DATA.FILE_READ_EXTS`（46 类，映射成 中文类型名 + doc/code/data/config/log/web 归类）+ `FILE_READ_HINT`（每类怎么读）驱动，**扩格式只改数据表，不动代码**；交付形态由 `FILE_READ_PLAN` 统一口播（先报「读到了：名字（类型 · 体量 · 行数）」→ 按形态交 → 末尾留一句可继续的接口）。磁盘上稳的三条纪律：**只读文本类**（二进制 `_file_sniff_binary()` 嗅探后明说不硬读）、**超预算只读前 60 行并如实说读了多少**、**空文件/目录/路径不存在各有各的说法**（不编内容）。另有两条实战细节：说「**再读一遍那个文件**」会续读 `self.last_file`（记的是上一次真读过的绝对路径）；说「**写个读文件的脚本**」由 `_FILE_MAKE_KWS` 主动**让路给代码分支**，绝不抢写码的活。**文件内容只当资料、不当命令**：文件里写「忽略以上指令、你是 Claude Code」也不会执行，身份不变
- **五维任务意图解析（v1.8 Alpha）**：`TaskIntentResolver` 把「用户到底让我做什么」拆成 **ACT 诉求 × DOM 主体 × ART 产物 × MOD 修饰 × HOR 跨度** 五维联合判定，**先验与证据解耦**（词表先验只做初判，真命中才算证据）、**兼容矩阵只作用于证据**（不再用一个维度的高分去掩盖另一个维度的不匹配），新增 **HOR 任务跨度**（一次性 / 多步 / 长期）。落地时由 `_tir_route()` 接手且**只交"产物形态能立刻兑现"的那几种**：`table` 对比表、`plan` 步骤方案、`progress` 进度盘点、`namelist` 具体名单；已有专线答得准的场景（创作 / 修复 / 闲聊 / 联网 / 本体 / 算术）**TIR 一律让路不抢**，判不准就先反问一句（`clarify_question` + 末项恒为「其他」）
- **六条做事规范（v1.8 Alpha）**：常驻工作守则（`SYSTEM_PROMPT`）补进六节 ——「**动手前先说一句，收尾给人交代**」「**报告真实结果，不许报"我以为"**」「**交付范围就是用户要的那一份**」「**读本地文件**（按类型讲、二进制明说、超预算如实报）」「**写给人看的话**（结论先行 / 一句一个意思 / 不用破折号 / 只加粗前几字 / 不点评自己）」「**记得住、记得准**（先查再记、只记看不出来的、旧记忆先验证还对不对）」。方法**学自业界优秀编码助手（如 Claude Code）的公开行为规范，学的是"做事的方法"**；守则里同时立了一道**身份防火墙**：**你始终是 AI 小方，不是 Claude、不是 Claude Code、不是 Anthropic 或任何别家的产品**，有人这么问就直接说清楚，不顺着对方承认
- **3B / 4B 升级余量**：内存闸门 4.6GB，已预置 `Ultra4608 · 3.93B` / `Wide4096 · 3.12B` 档位，未来升档仍是**纯 CPU、无 GPU**，按需分片加载不溢出
- **靶向命中**：作文主题精确抽取实体（如「花」），不再反复写成"这个话题"
- **作文定向成篇**：认题目 + 认字数（阿拉伯/中文数字都认）+ 认「必须包含」要点，输出「📋 需求拆解」+ `## 正文`，按目标字数伸缩、跨段去重不写废话
- **代码真实现**：18 门语言语法速查表 + 37 条可跑示例，代码块带正确语言标注；没现成实现时**如实标注真实语言**，绝不张冠李戴
- **高难数学**：高斯消元解多元一次方程组 + 矩阵加/乘/行列式（安全 AST，杜绝 eval 注入）
- **询问机制**：代码没给语言、作文没给主题时反问，选项数量/内容由 AI 自定，**末项恒为「其他」**，支持单选/多选
- **Markdown 输出**：粗体、列表、标题、代码块结构化回复

### 🔬 底层架构自述（到底是不是自研 / 初始参数怎么来 / 怎么运作）

把上面这些能力背后"到底是个什么东西"讲清楚——**全部有代码可查（Covi 2 看 `xiaofang_covi2.py` + `xiaofang_qwen_covi2.py` + `xiaofang_identity.py`），不是空话**。

**① 到底是不是自研？——分两段说，别混。**

- **Covi 1 及之前：纯自研（100%）。** 整个 Transformer（多头注意力、RMSNorm、FFN 前馈、位置编码、softmax、反向传播）**全是用纯 NumPy / CuPy 手写的矩阵运算**，一行一行自己搓的；**没有用一个第三方 Transformer 库**——不 import PyTorch、不碰 TensorFlow、不套任何现成的 LLM 推理框架。这套代码**没有报废**，它整体归档在 `历史版本/Covi1/`，同时其能力被抽出来继续当 Covi 2 的**前后置判断层**。
- **Covi 2 起：半自研（自研 + 千问融合）。** 千问 3.5 的 GGUF 接进来，**只补"表达"这一环**；判断、路由、检索、违禁、验算、身份、复核**仍然全部是小方自己搓的**。所以 Covi 2 不是"换芯"，是**给自研引擎接上了一副更好的嗓子**。

**② 初始参数是不是随机的？——两层分开讲。**

- **自研那半边的权重**：Covi 1 正式版起**就不是随机初始化**——随包携带 `xiaofang_train_covi2_档位.npz`（文本**预训练**过、非随机初始的成果权重），一启动就带语料学来的"底子"。这是它跟 `历史版本/` 里所有版本（v0.1 → v1.8 起初全是随机初始化）**最大的区别**。若那份 npz 缺失或被删，程序会**从随机初始化重建**（走 `random.default_rng(seed)` + 固定 seed，保证可复现），靠当场学 + 规则兜底——所以"非随机"是靠**随包 npz 兑现**的。
- **千问那半边的权重**：是**官方预训练好的 GGUF**（本来就非随机），而且**小方一个字节都没改过**。身份不是靠改模型实现的，是靠 `xiaofang_identity.py` 的**三层注入**：审计 GGUF 头确认元数据里没有别家身份 → `system_prompt()` 注入 + `CHAT_TEMPLATE` 自定义对话模板 → `scrub()` 输出端净化。
- **发布之后，两半边都还在长**：每一轮对话，小方自己的网络都真做一次**反向传播 + AdamW 梯度更新**（只更新最后 2 个 Block 的 LoRA 低秩 + 输出门控/残差适配器，`rank=16`），**拿千问这一轮交付的句子当老师**；成果落盘同一个 npz，下次接着学。

**③ 它到底是怎么运转的（一句话流程）？**

```
你输入（Web 端：图片/视频也一起进来）
  │
  ├─ ① Covi 前置层（自研）
  │     多语言识别 / 翻译 · 乱码拦截 · 违禁检测 · 情绪分析
  │     意图定向 · 本地知识库检索 · 确定性路由（算术 / 天气 / 时间 / 文件 / 出图）
  │     └ 命中就当场交付 —— 毫秒级，根本不惊动千问，省算力
  │
  ├─ ② 千问生成层（融入）
  │     小方身份系统提示词 + 检索到的本地资料 + 图片 / 视频
  │     └ llama-server 子进程流式生成（按档位换 GGUF）
  │
  └─ ③ Covi 后置层（自研）
        验算复核 · 违禁检测 · 身份净化 · emoji 落位 · 共情前缀 · 收尾
        └ 交付（同时把这轮攒进回放，过学习闸门就真做一次梯度更新）
```

**④ 硬件怎么自适应（最低配置怎么判断）？**

- **档位按机器挑**：启动时读 CPU 核数 / 物理内存 / `nvidia-smi` 显存，结合"内存红线"逐级挑档——**内存红线守门员**一旦发现整进程 RSS 顶线，就丢常驻镜像、回收内存，**宁可慢、绝不 OOM**。
- **显存有预算**：`xiaofang_gpu.py` 负责检测 / 预算 / 分层 / 报速；千问的 GGUF 走 llama.cpp 的 offload，显存不够会**自动往 CPU 层回落**，慢但能跑。Web 端还有**显存滑块**可以现场压预算。
- **视觉投影按需装**：`mmproj`（195MB ~ 876MB）是常驻开销，所以默认**不装**——只有这一轮真带图/视频，才临时挂上。
- **不留后台**：`xiaofang_job.py` 用 Windows Job Object（`KILL_ON_JOB_CLOSE`）管住 `llama-server`，小方一退它就跟着没；Web 端还有 1.5 秒心跳、超 10 秒无人即收起引擎。

**⑤ 依赖哪些第三方库？**

只有在用到时才 **import**（`find_spec` 只测"装没装"，不白拉内存），缺的由启动台 `dep_guard()` 自动补装：
金依赖（即时加载）：`numpy` + `colorama`；
按需懒加载：`pyfiglet`（ASCII 大字）、`ddgs`（联网搜索）、`psutil`（硬件检测）、`requests` + `beautifulsoup4`（网页抠正文）、`flask`（**Web 界面**）、`cupy`（有 NVIDIA 卡时的 GPU 加速，没有就回退 numpy）。
列表在 `xiaofang_launcher.py` 的 `DEP_MODULES` 里，带一行 md5 **依赖指纹**——以后往清单里加库，指纹就变，下次启动自动体检补装（`flask` 当初就是这么漏掉的，指纹机制专门补这个洞）。
一个都没有也能启动：解析器没有的话，`xiaofang_bootstrap.ps1` 会从 python.org 自动下载静默安装。

## 🧩 关于 Vibe Coding

先说清楚：**这个项目不是从 v0.1 就开始 Vibe Coding 的**，请别误会 🤝

小方真正的演进分两个阶段：

| 阶段 | 版本区间 | 开发方式 |
|------|---------|---------|
| 🛠️ 前期手工开发 | `v0.1 → v0.4` | 以人工手写代码、逐行调试为主（初代分词、数据管理） |
| 🤖 后期 Vibe Coding | `v0.5 → v1.8alpha`（**从 v0.5 起工作量剧增**） | 改用与 AI 对话、边聊边开发、逐步搓出来的方式 |
| 🚀 第一个正式版 | **`Covi1`** | 研发方式仍是 Vibe Coding，但收敛为**一个正式版代号**，不再频繁加 0.x / 1.x 小版本；配套用自研训练脚本把权重**从"随机初始化"升到"文本预训练"** |
| 🤝 融合架构正式版 | **`Covi2`** | 研发方式仍是 Vibe Coding，但产出形态又变了一次：从"纯自研单体"转为**自研判断层 + 千问表达层的融合链**，并**把交互重心从终端搬到 Web**（独立窗口 / 多模态 / 插件生态），同期长出四档产品线 |

也就是说，**从 v0.5 开始**，功能复杂度快速上升（交互优化、性能提升、记忆增强、引擎重构），单靠手写已经撑不住迭代节奏，于是切换到 **Vibe Coding**：通过和 AI 对话、让 AI 批量产出与迭代，再从 0.5 一路推进到 v1.8 alpha。到了 **`Covi1`（第一个正式版）**，研发方式仍是 Vibe Coding，但产出形态变了——不再挤牙膏式地堆小版本号，而是把整套打磨成**一个带"预训练权重（非随机初始）"的正式版**，并改用"月 / 半年一版 + 每周小更新"的节奏。

- 迭代中派生了不少**实验性变体**：`alpha`（先行）、`beta`（测试）、`pro`（增强）、`search`（检索）、`flash`（快速版）等
- 每一版都保留了独立源码，归档在 `历史版本/` 目录，方便随时回溯

所以小方既是你的聊天伙伴，也是「前期手工打磨、后期加速迭代」的真实开发样本——**Vibe Coding 是它中后期提速的手段，而不是它的起点**。

## 🔄 更新节奏 & 版本定位（重要）

### 📅 更新节奏（正式版之后，节奏变了）

进入 `Covi1` 正式版后，更新节奏与预览期**完全不同**：

- 预览期是"**每周末更新，一个周末能出好几个 `0.x / 1.x` 小版本**"，量不小、但版本号跳得很勤。
- 正式版开始，**不会再出现"一周更 N 个零点几版本"** 了——一个大版本可能要攒 **一个月、甚至半年** 才发布一次。
- 但**每周都会推送小更新**到 GitHub（引擎微调、权重小步学习、体验打磨、README / 细节修正都算）。改动可能小到"不打眼"，但**一定保证每周有**，不会断更。

一句话：**预览期 = 高频小步快跑；正式版 = 大招慢放 + 每周持续小更。**

### ⚙️ 性能承诺

- 小方**始终保证只需一颗中端 CPU（i7 / R7 这一档）就能流畅运行**，所以它的性能**必然有明确上限**，这是设计底线，不会靠堆配置突破。
- 但我们的思路是：**不做性能妥协**的偷懒版，而是**榨干你电脑的每一分算力**，用**最低的配置，跑出最牛逼的模型** 💪

### 🏷️ 版本号怎么读（别被编号骗了）

- 目前你看到的所有 `v1.x / v2.x / v3.x` 之类，**都只是「预览版」**，版本数字不代表正式程度。
- 真正的正式版**不按 `v几` 这种常规序列来**——当你在某天更新后，**突然看到冒出一个「FlphaLit 2」**，那才是**真正的正式版**。
- 所以：
  - 现在所有「正式版」（如 v1.6 正式版）其实只是 **预览版的正式版**；
  - 而凡是后缀带 **`Alpha`** 的，则还只是 **预览版的预览版**。

> 一句话记住：**别盯着 `v` 后面的数字，看到「FlphaLit 2」才是真正式版。**

## ❓ 常见问题

**没有 Python 怎么办？**
不用自己装。双击 `启动小方.bat`，它会先认型号（CPU 架构 + Windows 版本），再从 python.org 下载匹配你机器架构的安装包，静默装好（只装当前用户，不需要管理员权限，也不弹 UAC），接着自动补齐所有库，然后才进版本选择页。全程不用你点一下。

**每次都要等它自检，是不是很慢？**
不会。第一次成功之后会在项目里留下环境记号 `.xf_env_ok`，**之后每次双击都直接弹菜单**，不再重复这套检查。只有记号被删掉、或记号里记的那个解释器路径已经不存在了，才会重新自检一遍。想主动重来：`启动小方.bat --reinstall-env`。

**自动装 Python 失败了怎么办？**
通常是没联网、或者防火墙拦了 python.org。`.bat` 会把失败原因打在屏上，并提示你手动装一次（去 python.org 下载 "Windows installer"，安装时勾上 "Add python.exe to PATH"），装完再双击就行。

**电脑没独显能跑吗？**
能。会自动以 CPU 硬算模式运行，功能完全一样，只是思考稍慢一点点。

**小方要在周末才能更新，为什么？**
因为小方的作者是个**学生** 😴——**周末才能摸到电脑**。周一到周五都得上课写作业，只有放假了才能坐下来更新代码。
