# 小方AI (XiaoFang AI)

一个用 Python 开发的 AI 聊天助手「小方」的完整工程，包含从 v0.1 到最新版的全部历史版本与最终版本。

## 主要文件

- `xiaofang_settings.py` —— 小方的配置设置
- `xiaofang_data_v11pro.py` —— 小方的数据管理（最新版）
- `xiaofang_v11pro.py` —— 小方主程序（最新版）
- `_smoke_test_v11pro.py` —— 冒烟测试（最新版）
- `启动小方.bat` —— Windows 一键启动脚本

## 目录说明

- `历史版本/` —— 历次迭代版本归档（v0.1 → v1.1alpha）
- 顶层目录为当前最新版本

## 运行方式

双击 `启动小方.bat` 即可启动，或使用 Python 运行主程序：

```bash
python xiaofang_settings.py
python xiaofang_v11pro.py
```
