## 🚀 怎么启动（最简单的用法）

### 方式一：双击一键启动（推荐）

双击桌面「AI 小方」文件夹里的 **`启动小方.bat`**，搞定。

这个脚本会自动帮你：
1. 检测 Python —— 没有就自动下载安装 Python 3.12
2. 检测依赖（numpy / colorama / pyfiglet / ddgs / psutil）—— 缺了就自动 pip 安装
3. 检测有没有 NVIDIA 显卡 —— 有就启用 GPU 加速（CuPy），没有自动用 CPU 硬算
4. 启动小方

### 方式二：命令行手动启动

```bash
# 进入项目目录后，运行主程序即可（settings 和数据文件会被自动加载）
python xiaofang_v15.py
```

> 小提示：`xiaofang_settings.py` 是设置文件，一般不用手动运行；小方会在聊天里帮你改设置。

### 基础要求
- Windows 系统（bat 一键启动基于 Windows）
- Python 3.10+（推荐 3.12，脚本会自动装）
- 独立显卡可选——有就更快，没有也能跑

## 🧠 架构说明（技术内幕）

小方不依赖任何云端大模型，是一条**完整的本地小型语言模型流水线**：

```
你输入 → Tokenizer(分词) → 意图/情绪识别 → 深度思考(n-gram 生成)
        → 回答选择与润色 → 输出（带打字机效果）
```

核心模块：

| 文件 | 职责 |
|------|------|
| `xiaofang_v15.py` | 主程序。引擎入口、UI、对话循环、思考层、联网搜索 |
| `xiaofang_data_v15.py` | 数据文件。常用词词典 / 情感词典 / emoji 库 / 回答词库 / 本地知识库 |
| `xiaofang_settings.py` | 设置持久化。在聊天里改设置会回写此文件 |
| `xiaofang_memory_v*.json` | 记忆数据。小方记住的"跟你聊过的事" |
| `_smoke_test_v15.py` | 冒烟测试，验证核心功能可用 |
| `启动小方.bat` | Windows 一键启动器（环境检测 + 依赖安装 + 启动） |

### 关键技术亮点

- **Tokenizer**：自研 FMM 正向最大匹配分词器，不依赖 jieba 等外部分词库
- **情感引擎**：内置情绪词典、emoji 权重、标点/表情情感判定（`！！`=激动、`😭`=难过）
- **多轮思考模式**：`think`（默认单轮）/ `multi`（多轮，类 DeepSeek 风格）/ `off`（直出最快）
- **硬件自适应**：启动时检测 CPU 核数 / 内存 / 显卡显存，自动匹配合适规模的向量空间，低配也能跑
- **GPU 加速**：有 NVIDIA 卡自动走 CuPy/CUDA，显存实时算；无卡自动回退 numpy CPU 硬算
- **联网搜索**：多后端（duckduckgo / bing / brave / google / auto），可开关
- **Transformer 升档**：v1.5 维度再次加大至 **1.5–1.7B 参数**（旗舰档），31GB 大内存机器自适应选中，机器小自动降档
- **靶向命中**：作文主题精确抽取实体（如「花」），不再反复写成"这个话题"
- **高难数学**：高斯消元解多元一次方程组 + 矩阵加/乘/行列式（安全 AST，杜绝 eval 注入）
- **询问机制**：代码没给语言、作文没给主题时反问，选项数量/内容由 AI 自定，**末项恒为「其他」**，支持单选/多选
- **Markdown 输出**：粗体、列表、标题、代码块结构化回复

## 🧩 关于 Vibe Coding

先说清楚：**这个项目不是从 v0.1 就开始 Vibe Coding 的**，请别误会 🤝

小方真正的演进分两个阶段：

| 阶段 | 版本区间 | 开发方式 |
|------|---------|---------|
| 🛠️ 前期手工开发 | `v0.1 → v0.4` | 以人工手写代码、逐行调试为主（初代分词、数据管理） |
| 🤖 后期 Vibe Coding | `v0.5 → v1.5`（**从 v0.5 起工作量剧增**） | 改用与 AI 对话、边聊边开发、逐步搓出来的方式 |

也就是说，**从 v0.5 开始**，功能复杂度快速上升（交互优化、性能提升、记忆增强、引擎重构），单靠手写已经撑不住迭代节奏，于是切换到 **Vibe Coding**：通过和 AI 对话、让 AI 批量产出与迭代，再从 0.5 一路推进到 v1.5 正式版。

- 迭代中派生了不少**实验性变体**：`alpha`（先行）、`beta`（测试）、`pro`（增强）、`search`（检索）、`flash`（快速版）等
- 每一版都保留了独立源码，归档在 `历史版本/` 目录，方便随时回溯

所以小方既是你的聊天伙伴，也是「前期手工打磨、后期加速迭代」的真实开发样本——**Vibe Coding 是它中后期提速的手段，而不是它的起点**。

## 🔄 更新节奏 & 版本定位（重要）

### 📅 更新节奏

小方会**每周末更新**，而且每次更新的量都**不小**——功能、性能、记忆、体验会持续迭代。

### ⚙️ 性能承诺

- 小方**始终保证只需一颗中端 CPU（i7 / R7 这一档）就能流畅运行**，所以它的性能**必然有明确上限**，这是设计底线，不会靠堆配置突破。
- 但我们的思路是：**不做性能妥协**的偷懒版，而是**榨干你电脑的每一分算力**，用**最低的配置，跑出最牛逼的模型** 💪

### 🏷️ 版本号怎么读（别被编号骗了）

- 目前你看到的所有 `v1.x / v2.x / v3.x` 之类，**都只是「预览版」**，版本数字不代表正式程度。
- 真正的正式版**不按 `v几` 这种常规序列来**——当你在某天更新后，**突然看到冒出一个「FlphaLit 2」**，那才是**真正的正式版**。
- 所以：
  - 现在所有「正式版」（如 v1.5 正式版）其实只是 **预览版的正式版**；
  - 而凡是后缀带 **`Alpha`** 的，则还只是 **预览版的预览版**。

> 一句话记住：**别盯着 `v` 后面的数字，看到「FlphaLit 2」才是真正式版。**

> ### ⚠️ v0.5 的墓志铭（一次过于激进的教训）
>
> `v0.5` 刚切换到 Vibe Coding 时**步子迈得太大**，一口气给 v0.5 新增了 **4 个测试变体**（alpha / alpha2 / beta / flash）做对比，正式版更是直接把规模**堆到 4096 维、24 层、32 头**的极限配置。

>
> 之后的版本（v0.6 起）把性能目标重新拉回"i7/R7 单 CPU 也能流畅运行"的务实路线，参数规模让位于可用性 💪

## ❓ 常见问题

**没有 Python 怎么办？**
双击 `启动小方.bat`，它会自动下载安装 Python 3.12 并配好环境。

**电脑没独显能跑吗？**
能。会自动以 CPU 硬算模式运行，功能完全一样，只是思考稍慢一点点。

**小方要联网吗？**
不需要。核心对话完全本地离线运行；只有你主动问天气/搜东西且开启联网时才联网。

**设置存在哪？**
`xiaofang_settings.py`。在聊天框输入 `/setting` 修改后会自动写盘，下次启动生效。
