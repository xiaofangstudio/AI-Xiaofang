# 🤖 AI 小方 (XiaoFang AI)

一个完全**本地运行、纯自研**的中文 AI 聊天助手，由「小方工作室」开发。小方不调用任何第三方大模型 API，对话、思考、情绪识别全在你自己的电脑上完成。

> 当前最新版本：**v14alpha · FlphaLit 引擎**（FlphaLit = 自研的轻量本地语言模型）

---

## ✨ 它能做什么

小方是一个贴心的桌面闲聊助理，主打**有性格、有情绪、会思考**。你可以：

| 场景 | 举例 |
|------|------|
| 💬 日常聊天 | 「你好呀」「今天心情怎么样」 |
| 🧠 深度思考 | 复杂问题时先"想清楚"再回答（可开启打字机效果） |
| 😊 情绪互动 | 识别高兴/难过/生气，用匹配语气回你 |
| 🌤️ 联网搜索 | 「今天天气」「帮我搜一下 XX」（多后端联网） |
| 🎯 方言幽默 | 接梗、讲笑话、写小诗、编故事 |
| 🧩 记忆陪伴 | 记住你之前说过的事，下次接着聊 |

## 🚀 怎么启动（最简单的用法）

### 方式一：双击一键启动（推荐）

双击桌面「AI 小方」文件夹里的 **`启动小方.bat`**，搞定。

这个脚本会自动帮你：
1. 检测 Python —— 没有就自动下载安装 Python 3.12
2. 检测依赖（numpy / colorama / pyfiglet / ddgs / psutil）—— 缺了就自动 pip 安装
3. 检测有没有 NVIDIA 显卡 —— 有就启用 GPU 加速（CuPy），没有自动用 CPU 硬算
4. 启动小方

### 方式二：命令行手动启动

```bash
# 进入项目目录后，运行主程序即可（settings 和数据文件会被自动加载）
python xiaofang_v14alpha.py
```

> 小提示：`xiaofang_settings.py` 是设置文件，一般不用手动运行；小方会在聊天里帮你改设置。

### 基础要求
- Windows 系统（bat 一键启动基于 Windows）
- Python 3.10+（推荐 3.12，脚本会自动装）
- 独立显卡可选——有就更快，没有也能跑

## 🎮 常用命令与快捷键

在聊天框直接输入：

| 命令 | 作用 |
|------|------|
| `/help` | 打开命令手册 + 快捷键面板 |
| `/setting` | 进入设置（思考模式/情绪敏感度/联网开关等，改完自动存盘） |
| `/prev` | 查看上一条回复 |
| `/undo` | 回退上一条 |
| `/exit` | 退出程序 |

> 在支持的环境下，还能用 **F1–F6** 快捷键（F1 帮助 / F3 回退 / F4 新对话 / F5 停止 / F6 退出 / F7 面板）。
> 环境不支持逐键读入时会自动退回普通 `input()`。

## 🧠 架构说明（技术内幕）

小方不依赖任何云端大模型，是一条**完整的本地小型语言模型流水线**：

```
你输入 → Tokenizer(分词) → 意图/情绪识别 → 深度思考(n-gram 生成)
        → 回答选择与润色 → 输出（带打字机效果）
```

核心模块：

| 文件 | 职责 |
|------|------|
| `xiaofang_v14alpha.py` | 主程序。引擎入口、UI、对话循环、思考层、联网搜索 |
| `xiaofang_data_v14alpha.py` | 数据文件。常用词词典 / 情感词典 / emoji 库 / 回答词库 / 本地知识库 |
| `xiaofang_settings.py` | 设置持久化。在聊天里改设置会回写此文件 |
| `xiaofang_memory_v*.json` | 记忆数据。小方记住的"跟你聊过的事" |
| `_smoke_test_v14alpha.py` | 冒烟测试，验证核心功能可用 |
| `_ui_check_v14.py` | UI 自检工具 |
| `_apply_v14startup.py` | 启动画面补丁脚本 |
| `启动小方.bat` | Windows 一键启动器（环境检测 + 依赖安装 + 启动） |

### 关键技术亮点

- **Tokenizer**：自研 FMM 正向最大匹配分词器，不依赖 jieba 等外部分词库
- **情感引擎**：内置情绪词典、emoji 权重、标点/表情情感判定（`！！`=激动、`😭`=难过）
- **多轮思考模式**：`think`（默认单轮）/ `multi`（多轮，类 DeepSeek 风格）/ `off`（直出最快）
- **硬件自适应**：启动时检测 CPU 核数 / 内存 / 显卡显存，自动匹配合适规模的向量空间，低配也能跑
- **GPU 加速**：有 NVIDIA 卡自动走 CuPy/CUDA，显存实时算；无卡自动回退 numpy CPU 硬算
- **联网搜索**：多后端（duckduckgo / bing / brave / google / auto），可开关

## ❓ 常见问题

**没有 Python 怎么办？**
双击 `启动小方.bat`，它会自动下载安装 Python 3.12 并配好环境。

**电脑没独显能跑吗？**
能。会自动以 CPU 硬算模式运行，功能完全一样，只是思考稍慢一点点。

**小方要联网吗？**
不需要。核心对话完全本地离线运行；只有你主动问天气/搜东西且开启联网时才联网。

**设置存在哪？**
`xiaofang_settings.py`。在聊天框输入 `/setting` 修改后会自动写盘，下次启动生效。
