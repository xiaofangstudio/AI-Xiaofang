# 小方 · 细节打磨 + 模型三档分裂（2026-09-19 v3.8）

## 一、背景小方：恢复方形 + 黑白 + 露眼 ✅
原图本就是**方形、青底+两根黑色竖条**的方图标。把 `border-radius:86px`（那个把它变圆的罪魁）改回**小圆角 22px**；`grayscale` 由 .5 拉到 **1（纯黑白）**、`contrast` 提到 1.45、压亮度——于是那两条黑色竖条从淡青背景里浮出来，就是它的"眼睛"：睁着的、看得见。

## 二、3D 旋转景深调小 ✅
按用户要求"做但要小一点"：旋转幅度 ±6°/1.8° → **±3°/0.8°**，纵深位移 42px → **22px**，scale 1.03 → 1.015。还是看得出立体，但不晃眼。

## 三、启动 0102 数字彩蛋 ✅
刚打开欢迎页，卡片顶部先出现 `0 1 0 2 0 3 0 4`（.v-sign），**一个数字一个数字带弹跳弹进来**（每 0.13s 一位，像开机自检），全跳完再整块淡出，才轮到标语逐字打字。新的 `.vsig` 动画 + `runVSign()` 驱动，浏览器实测 **8 个数字全部点亮成功**。四个快问按钮（chips）开场**随机打乱顺序**，不回回念稿。

## 四、上拉菜单 → 顶部弹出 ✅
`showPop()` 改为**紧贴页面最上方（距顶 10px）展开**，不再赖在按钮旁往下坠；动画换成 `popup`——从顶部往下推（transform-origin: top），视觉是"整个从最上面顶出来"。浏览器实测**位置符合要求**。

## 五、打字机暂停（点击输入框）✅
输入框 `focus` → `pauseType(true)`：正在打的字**停在原地、不清空不消失**、光标留在原处；失焦 `pauseType(false)` 接着打。用 `twResumeSig` 世代号防止旧计时器越权续打。

## 六、消息排队机制 ✅
`send()` 现在走 `sendChain` 串行队列：**小方还没答完上一条，新消息照发不误**，自动排在队列里；前面全部处理完，这条自己接着发出。**可多条排队**。点停止清空队列。

之前三档 2.40 / 2.48 / 2.50B（头尾只差 0.1B，等于换名字的同一台）。现在整条产品线重新排，**参数真正阶梯化**：
